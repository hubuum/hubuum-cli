# Hubuum CLI

Work with Hubuum from a terminal: run a single command, explore interactively in
the REPL, or automate repeatable workflows with scripts and extensions.

## Start here

- [Install, configure, and connect](getting-started.md).
- [Search your inventory](search.md).
- [Shape command output with pipelines](output-pipeline.md).
- [Check server compatibility](compatibility.md).

## Automate a workflow

Start with the [extension tutorial](extension-tutorial.md), explore
[recipes](extension-recipes.md), and inspect the working examples. Operations that
change credentials require [fresh approval](credential-approvals.md). Long-running
work can be followed through [tasks](tasks.md).

The CLI connects through the server's HTTP API. The separately shipped
`hubuum-admin` executable performs local server administration. See
[server operations](https://hubuum.github.io/hubuum/) and the
[Hubuum ecosystem](https://hubuum.github.io/) for the other interfaces.
