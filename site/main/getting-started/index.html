Hubuum CLI¶

Run commands, explore interactively, or automate Hubuum from a terminal. CLI v0.0.19 (2026-10-23) uses Rust client 0.17.0 and targets server v0.0.20. Hubuum is under active development before 1.0.

This release restores persistent logins and adds historical views, credential activity, hydration, and query observation controls. The room wrapper now fetches placement and object data with a depth-two graph.

Documentation · Hubuum ecosystem

Release binaries¶

Download and extract the archive for your platform from release v0.0.19. Verify its published SHA-256 checksum and place hubuum-cli (hubuum-cli.exe on Windows) on your PATH. Linux x86_64/ARM64, macOS Apple Silicon, and Windows x86_64 binaries are available. See binary details.

hubuum-cli version

Updating in place¶

Use hubuum-cli self-update --check to inspect the latest stable release. See update and restart instructions before installing it, including package-manager and platform restrictions.

Compatibility¶

The development branch uses client 0.19.0 with the same server target and adds related-object list filters.

CLI v0.0.19 uses client 0.17.0 and targets server v0.0.20. Check the compatibility matrix for the server you use. For server upgrades, follow the server's release instructions; for CLI recovery commands, see backup and restore.

Password sessions persist in files by default; select --session-storage none for memory-only use or opt into macOS Keychain/Linux Secret Service. The server target and backup format 10 are unchanged from v0.0.18. See authentication migration. Breaking for wrapper-only upgrades: upgrade hubuum-room together with CLI v0.0.19; the wrapper requires relation object graph --data.

Usage¶

You need a server URL and a human account with permission to read its data. Connect to a TLS-enabled server; the CLI prompts for the password:

hubuum-cli --hostname hubuum.example.com --protocol https --port 443 \
  --username alice collection list

For a local HTTP evaluation server, use --hostname 127.0.0.1 --protocol http --port 8080. Global options go before the command. See authentication for provider scopes, token files, and session recovery.

After loading Atlas and granting your account read access, list its three Server objects:

hubuum-cli --hostname hubuum.example.com --protocol https --port 443 \
  --username alice object list --class Server

Expect web-01, web-02, and worker-01. To keep a session open, omit the command and use the interactive REPL. help --tree lists available commands.
